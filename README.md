# Personal Portfolio Website

A modern, responsive **personal portfolio website** built with **HTML, CSS, and JavaScript**.  
It showcases projects, experience, and skills in a clean and interactive way.

---

## ✨ Features
- **Smooth Navigation** – Click on nav links to scroll smoothly to different sections.
- **Active Section Highlight** – Current section link gets highlighted in the navbar.
- **Typing Effect** – Animated typing effect for the name in the header.
- **Scroll Animations** – Projects and experience items fade & slide in on scroll.
- **Responsive Design** – Works across desktops, tablets, and mobile devices.

---

## 🛠️ Technologies Used
- **HTML5** – Structure of the site.
- **CSS3** – Styling, layout, and responsiveness.
- **JavaScript (Vanilla)** – Interactivity and animations.
